# NextGen reforecast software / manuscript outline

Start with `SOFTWARE_AND_MANUSCRIPT_OUTLINE.md` or its formatted Word equivalent.

This is a proposed software and publication design for Environmental Modelling & Software, separate from the HYDRA correction manuscript and Candidate A/B experiments. No generator software was implemented, no model runs were launched, and no public repository was created.

`AGENT_INFORMATION_REQUEST.md` is a targeted read-only request for the codebase agents. It is designed to resolve extraction, version, runtime, recovery, minimal-example, licensing and benchmark questions without rebuilding the large review bundle.

`SOURCE_INSPECTION_NOTES.md` records narrowly inspected archived source/audit excerpts and their file identities. Historical reports are not represented as new execution evidence.

The outline's public-software name and CLI are illustrative, not installed tools. Compatibility, measured performance, independent reproducibility and exact journal submission requirements remain subject to the checks described in the report.
