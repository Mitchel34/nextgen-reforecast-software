## Interface decisions for this increment

- Schema 1.0 keeps its existing shape and 18-lead interpretation. Schema 1.1 adds an explicit retained interval and export projection; runtime completion still needs 18 steps and all forcing leads.
- A shorthand schedule expands deterministically to explicit UTC issues with an exclusive stop. A browser date range proposes inclusive **issue dates**, which the browser translates to an exclusive next-day boundary and explains with valid-time examples. This proposal is recorded for evaluation, not a declaration of source coverage.
- The browser exports a researcher request. It cannot create a runnable engine campaign without admitted domain, source, initialization and runtime preparation. Resolver, coverage, service and scientific-default gaps remain visible.
- Provenance work is an offline planning foundation. Bound hashes and metadata do not establish scientific interpretation, rights, physical equivalence or execution admission.

## Boundaries and next checkpoint
