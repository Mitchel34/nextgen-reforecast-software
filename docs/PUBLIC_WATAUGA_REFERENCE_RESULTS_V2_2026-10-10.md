The independent operational review also decoded the raw routing NetCDF with a different reader, h5py 3.16.0, and compared every one of the 876,804 routing rows and all three variables with the frozen normalizer's CSV: zero mismatches. It independently rechecked all native clocks/values, input hashes, executor/normalizer/driver bindings, process provenance and container limits.

Native stderr contains repeated upstream unit-interface warnings. Exact source tracing and log counts account for every conversion warning: the custom output writer requests unit `1` for all 15 fields, while CFE declares 14 in metres and the dimensionless scheme as `none`; the framework catches conversion errors and returns each original scalar unchanged. Source tracing confirms these configured zeros are retained as the SLOTH clock advances; runtime inputs were not directly instrumented. The physical Noah-to-CFE rainfall/PET conversions use the receiving input units and produced no such conversion warnings. Metadata therefore retains the actual CFE output units rather than relabelling values as dimensionless. The logs and malformed upstream interfaces remain disclosed, and strict unit-interface treatment is a prerequisite for the released executor. Full finite coverage and explained fallback behavior establish diagnostic output integrity, not physical accuracy.

## Configuration failure and separate revision

The v1 reference attempt failed. Its four reservations produced three actual model processes: a prelaunch transfer failure; a zero-exit land process whose tmpfs outputs were unavailable after a Docker-copy capture failure; and a zero-exit land initialization followed by a failed router with both logs/receipts retained. Noah printed `FATAL ERROR: model options: stomatal_resistance_option should be1-3` and stopped while returning exit code zero. No complete v1 reference was produced. The output loss remains explicitly recorded rather than described as preserved payloads.

Source review found two template settings unsupported by the pinned Noah implementation. The separately identified [v2 fixture](../fixtures/watauga-public-v2/README.md) changes `stomatal_resistance_option` 4→1 and `evap_srfc_resistance_option` 5→1 to exact pinned defaults. All 93 Noah files contain these two changes; the other 198 input files are unchanged. All 17 model-option fields pass source-bound range/implementation checks. The configuration change has its own identity and does not imply hydrologic improvement. Weather, geometry, CFE parameters, cold origin, catchment/reach axes and issues/horizons are unchanged.

The new executor validates the complete land/nexus output contract and fatal logs after native completion. It refuses routing when a zero-exit land process leaves incomplete output. Both transfer directions now use an independently checked in-container tar stream while tmpfs is mounted. Failed v1 inputs, tools, protocols, reservations and available evidence remain distinct from v2.
