## Recommended implementation sequence

Start with an ownership-checked, reproducible V3 build and one complete Watauga fixture. Then extract only the offline planner, qualified branch adapter, commit/verify logic and history-replay path. Preserve the original scientific source unchanged and compare the new package against it. Bring New River and concurrency into the same tests before adding convenience interfaces.

Use upstream preprocessing and execution environments where their exact contracts fit. Keep correction models, calibration, broad evaluation dashboards, hosted public services and cloud fleets outside the generator core. No invitations, maintainer emails, issues or other external messages were sent as part of this review.
