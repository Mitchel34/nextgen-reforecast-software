## Small future benchmark set — proposed, not run

| Order | Case | Fixed comparison and acceptance | Missing work / relative effort |
|---|---|---|---|
| 1 | Synthetic runtime mechanics | Exact issue clocks, open-file offsets, branch-only forcing pulse, parent/sibling isolation, deadline and child reaping; corruption must fail closed | Extract existing fixture and pin source preimages; small–medium |
| 2 | Watauga real reference | One origin, same physical realization and weather, two issue times and eighteen leads; compare same-weather branch with uninterrupted reference at all native/routing steps; retain original tolerance and full diagnostics | Complete redistributable domain/weather/runtime fixture and independent reference recipe; high |
| 3 | Serial/concurrent invariance | Same issue list, same bytes, fixed total CPU/memory allocation; vary concurrency only; report wall/CPU time, whole-job memory, I/O and archive hashes; repeated trials, including adverse runs | Instrument resource collection and CPU allocation; medium after case 2 |
| 4 | Child failure after parent advance | Inject failure before/after issue output and commit; reject partial output, reconstruct original history, retain verified committed issues and compare surviving/replayed results to reference | Public replay controller and explicit failure fixtures; high |
| 5 | Parent/host loss | Kill parent at declared boundaries; recover using exactly bound origin/history/configuration, measure replay overhead; absent/corrupt inputs must stop | Complete retained historical assets and independent durable replay proof; high |
| 6 | Source integrity | Missing interval, duplicate time, malformed key, swapped generation, NaN, wrong units, damaged archive and changed configuration; no silent replacement | Adapt existing negative tests to public schema; medium |
| 7 | Two domains | Repeat real reference and concurrency cases for Watauga and New River, preserving explicit geometry/parameter treatments; count nested outputs once at domain level | Resident New River fixture and redistribution clearance; high |
| 8 | Independent researcher reproduction | Clean qualified Linux environment, hash-bound install and small fixture, zero private author paths/services; one configuration-only variation; preserve failures and help required | Build/dependency/source attestation, usable docs, distribution and an independent operator; high |

Measure source discovery, retrieval, transforms, historical reconstruction, branching, routing, validation, I/O and recovery separately. Compare methods using the same scientific workload and total resource limits before attributing efficiency to history sharing. The benchmark implementation must not reconstruct antecedent history at each issue merely to exaggerate the reference cost. No calendar schedule, numerical speedup target or unmeasured resource promise is assigned.
